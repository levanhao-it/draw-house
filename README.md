# Font files

Place the following woff2 font files here before deploying:

- `BeVietnamPro-Regular.woff2`
- `BeVietnamPro-Bold.woff2`
- `Inter-Regular.woff2`
- `Inter-Bold.woff2`

Download Be Vietnam Pro from https://fonts.google.com/specimen/Be+Vietnam+Pro
Download Inter from https://fonts.google.com/specimen/Inter

Select weights 400 and 700 for each, download the woff2 subset that includes
the Vietnamese unicode range (U+1EA0–U+1EF9).
